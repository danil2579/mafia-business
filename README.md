# Mafia Business v3.0.0

Завершённая браузерная версия сетевой настольной стратегии для 2–8 игроков. Поддерживает обычную игру с одного устройства на игрока, TV‑режим с телефонами‑контроллерами, ботов, переподключение, чат, аккаунты и устанавливаемый PWA‑клиент.

## Быстрый запуск

Требуется Node.js 18 или новее.

- macOS: дважды нажмите `START.command` (при первом запуске macOS может попросить разрешение).
- Windows: запустите `START.bat`.
- Терминал: `npm start`.

Откройте `http://localhost:3001`. Для игры с телефонами в одной Wi‑Fi‑сети запустите через `START.command`/`START.bat` и откройте на устройствах `http://IP-НОУТБУКА:3001`.

Для игры через интернет сервер должен быть развёрнут на публичном HTTPS‑домене. Все игроки открывают один и тот же домен; комнаты существуют в памяти конкретного серверного процесса.

## Установка на ноутбук и телефон

Откройте «Настройки → Установить игру».

- Chrome/Edge на Windows, macOS и Android показывают системное предложение установки.
- Safari на iPhone/iPad: «Поделиться → На экран Домой».
- Установленная версия открывается как отдельное приложение. Для партии всё равно требуется соединение с игровым сервером.

## Команды

```bash
npm ci
npm test
npm run check
npm start
npm run release:source
```

Последняя команда создаёт переносимый архив `release/mafia-business-v3.0.0.zip`, включая установленные серверные зависимости.

## Продакшен

Скопируйте `.env.example` в конфигурацию хостинга и задайте как минимум:

- `NODE_ENV=production`;
- `ALLOWED_ORIGINS=https://ваш-домен`;
- `ACCOUNTS_FILE` на постоянном зашифрованном диске;
- `TRUST_PROXY=1`, только если сервер действительно находится за доверенным reverse proxy;
- `ENABLE_CHEATS=0`.

Трафик должен завершаться на HTTPS reverse proxy. Делайте резервные копии файла аккаунтов. Текущий файловый account store рассчитан на один процесс; для горизонтального масштабирования его нужно заменить PostgreSQL/Redis, а комнаты — вынести в общий authoritative game service.

## Безопасность

- Пароли хешируются `scrypt` с индивидуальной случайной солью и никогда не возвращаются клиенту.
- Сессии передаются в `HttpOnly; SameSite=Lax` cookie; в production также ставится `Secure`.
- Включены CSP, HSTS в production, запрет iframe, MIME sniffing и ненужных browser permissions.
- Socket.IO ограничивает размер и частоту сообщений; чат имеет отдельный flood‑limit.
- Токены переподключения генерируются криптографически и не позволяют занять чужое место по имени.
- Debug/cheat события отключены, если `ENABLE_CHEATS` не равен `1`.

Перед каждым публичным релизом выполните `npm audit --omit=dev`. Эта команда отправляет метаданные зависимостей в npm registry и потому не запускается автоматически в изолированной сборке.
